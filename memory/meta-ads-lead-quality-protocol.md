# Meta Ads Lead Quality Monitoring Protocol

## Daily Monitoring Routine (Part of Meta Ads Project)

### 1. Performance Metrics Check (8 AM, 2 PM, 8 PM)
- Pull spend, impressions, clicks, leads via API
- Compare to previous day and 7-day average
- Flag significant changes (>20% variance)

### 2. Lead Quality Validation (Daily at 6 PM)
**CRITICAL: Always verify with Jhauncy before celebrating lead volume**

**Process:**
1. Check Meta ads performance data
2. Message Jhauncy: "X leads from Meta today - converting? Quality vs usual?"
3. Check lead manager plugin status
4. Log Jhauncy's response in memory

**Key Questions for Jhauncy:**
- Are these leads converting to sales/opportunities?
- Quality comparison vs other lead sources?
- Any patterns in good vs bad leads (location, time, ad creative)?

### 3. Decision Making Framework

**If leads are high quality AND converting:**
- Increase budget for winning campaigns
- Scale similar audiences/creatives
- Document what's working

**If leads are low quality OR not converting:**
- Pause underperforming campaigns
- Adjust targeting (demographics, interests, behaviors)
- Request new creative from Ninad
- Test different lead forms/qualification questions

**If mixed quality:**
- Analyze patterns (which ads/creatives bring good leads?)
- Split budget: 70% to proven quality sources, 30% testing
- Set up lead scoring if not exists

### 4. Weekly Analysis (Mondays)
- Calculate true cost per QUALIFIED lead (not just form fills)
- ROAS based on actual sales, not lead volume
- Recommendations for budget allocation
- Coordinate with Jhauncy on lead quality trends

### 5. Documentation
- Save all lead quality feedback in memory files
- Track which campaigns/audiences bring best customers
- Update targeting based on actual customer profiles

## Integration with Meta Ads Project Tasks
This protocol becomes part of:
- 8 AM Performance Check + MCC Lead Cross-Reference
- 2 PM Midday Performance Check + Budget Optimization  
- 8 PM End-of-Day Summary + Next Day Strategy
- Coordinate with Jhauncy - Lead Quality Analysis (enhanced)

## Success Metrics
- Lead-to-sale conversion rate >15%
- Cost per qualified lead <$50
- Lead quality score >7/10 (per Jhauncy's assessment)
- Positive ROI on ad spend within 30 days
